I received an email from a blog directory saying that Neo Samurai looks
scrambled on Internet Explorer. So I frustratedly checked, and oh god what a
mess. I haven't used IE in ages, and have almost forgotten it existed even. But
I understand that many people still use it, so I'll try to adjust the frame
widths, sidebar link sizes, and other details like the good web designer I am.

That said, please consider using [Firefox](http://www.mozilla.com/firefox/) or
[Opera](http://www.opera.com/) instead. They are much better for viewing
websites in general, and this blog in particular!
